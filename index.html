核心功能

每一步都有理由，每一轮都有记录
🎯

四档判定 · 每岗给理由

A 优先 / B 权衡 / C 红线 / X 排除。每个岗位都列出命中哪条规则：日期窗口、住宿、薪资工时线、岗位红线、陷阱知识库——看得懂为什么进这档。

🧱

3D 岗位墙 + 求职邮件草稿

可考虑岗位以卡片墙呈现，点击即看判定理由、雇主联系方式与按你档案自动填充的英文求职邮件草稿，深链直达 IE 岗位页。

📈

历轮筛查记录 · 只筛新卡

每轮筛查自动记入历史：新核查 / 分档计数 / 陷阱新增 / 备注。已核查过的岗位自动标记「沿用」，例行筛查只处理新卡。

🕳️

陷阱知识库

沉淀历轮踩坑：卡片标题与详情页实岗不符案例、城镇治安、雇主联系方式、住房危机镇——知识随使用持续增长，越用越准。

技术亮点

为 AI 行业简历而生的架构叙事
1

AI Agent 工作流（Claude Code Skill）

以 Skill 生态封装完整 agent 流程：数据解析 → 规则引擎分档 → 报告生成 → 邮件个性化定稿 → 知识库维护，人机分工明确——确定性规则交给代码，创造性文案交给 AI。

2

知识库工程

岗位实岗映射、城镇治安库、陷阱案例库、雇主联系方式库分层沉淀，可复用到任何 Work & Travel 用户；知识更新有明确维护流程与单源同步机制（knowledge → webapp 数据快照）。

3

可复现评测基准

历史筛查数据回放测试：任何规则改动先跑全量回放、逐岗比对档位，0-diff 才视为安全——把「改规则不改坏旧结论」做成工程约束。

4

全静态 Web 工作台

零后端、零依赖：设置表单（点选式口径配置，导出 YAML）+ 报告渲染（拖入 JSON 在线看岗位墙与历轮表），GitHub Pages 即可托管，任何设备可用。
