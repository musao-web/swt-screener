它能做什么

每一步都有理由，每一轮都有记录
🎯

四档判定 · 每岗给理由

A 优先 / B 权衡 / C 红线 / X 排除。每个岗位都说明命中哪条规则：日期窗口、住宿、薪资工时线、岗位红线、陷阱库。

🧱

岗位墙 + 邮件草稿

可考虑岗位以卡片墙呈现，点击即看判定理由、雇主联系方式与按你档案自动填充的英文求职邮件草稿。

📈

历轮追踪 · 只筛新卡

每次筛查自动记入历史，已看过的卡自动标记「沿用」，例行筛查只处理新岗位。

🕳️

陷阱知识库

卡片标题与实岗不符、城镇治安、住房危机镇……踩过的坑沉淀进知识库，越用越准。

怎么用

三步上手
  1. 安装 + 设置你的标准装好 skill 后回答两轮问卷：想做什么 / 不想做什么（到岗离岗、住宿、岗位红线、薪资工时线……全部自己定），以及你的个人档案（填一次，之后自动复用）。
  2. 一条命令出报告登录 IE 浏览岗位，把看中的岗位交给工具——按你的标准自动分四档、记入历轮并生成报告，每个岗位都附判定理由。
  3. 挑岗 + 发邮件报告里看岗位墙 / 清单与求职邮件草稿，让 Claude 按你的档案个性化定稿，正式申请在 IE 站内完成。
